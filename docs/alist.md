# 用 Alist 把阿里云盘、百度网盘接入多点备份

阿里云盘、百度网盘、115 网盘等国内网盘没有提供 WebDAV。[Alist](https://alist.nn.ci/zh/) 能把这些网盘挂载起来，再以 WebDAV 的形式提供给多点备份使用。

整体关系：

```
Obsidian（多点备份） ──WebDAV──▶ Alist ──各网盘接口──▶ 阿里云盘 / 百度网盘 / …
```

> 注意：备份数据会经过你自己运行的 Alist。Alist 要放在你信任的设备上（家里的 NAS、电脑或自己的服务器），不要使用别人搭建的公共 Alist。

## 1. 安装并启动 Alist

任选一种方式，详细步骤见 Alist 官方文档。

- **Docker**（NAS、Linux 服务器推荐）：

  ```bash
  docker run -d --restart=unless-stopped -v /opt/alist:/opt/alist/data -p 5244:5244 --name alist xhofe/alist:latest
  docker exec -it alist ./alist admin random   # 查看或重置管理员密码
  ```

- **Windows / macOS / Linux 直接运行**：从 Alist 的 GitHub Releases 下载对应系统的程序，运行 `alist server`，第一次启动时终端会打印管理员密码。

启动后浏览器打开 `http://<Alist 所在设备的地址>:5244/`，用 `admin` 和上面的密码登录。

## 2. 挂载网盘

1. 登录后点页面底部的 **管理** → **存储** → **添加**。
2. “驱动”选择你的网盘，例如“阿里云盘 Open”或“百度网盘”。
3. “挂载路径”填一个名字，例如 `/阿里云盘`。
4. 按 Alist 文档为该驱动填写令牌（通常要在网盘的授权页面获取刷新令牌），保存。
5. 回到首页，能看到 `/阿里云盘` 并能打开里面的文件夹，说明挂载成功。

## 3. 开启 WebDAV 权限

1. **管理** → **用户**，编辑要使用的用户（建议新建一个专门给多点备份用的用户，不用 admin）。
2. 勾选 **WebDAV 读取** 和 **WebDAV 管理**（不同版本叫“WebDAV 读写”），保存。
3. 给这个用户设置一个密码；这个密码就是下面填进 Obsidian 的密码。
4. 新建用户时，“基本路径”可以设为 `/阿里云盘`，这样这个用户只能看到这个网盘。

## 4. 在多点备份中添加

1. Obsidian → 设置 → 多点备份 → **添加目的地** → **WebDAV**。
2. “服务”选择 **Alist（阿里云盘、百度网盘等）**。
3. “服务器地址”填 Alist 地址加 `/dav/`，例如 `http://192.168.1.10:5244/dav/`。
4. “用户名”“密码”填第 3 步的用户；密码在“选择…”中新建一个密钥粘贴进去。密码只保存在这台设备的密钥存储中。
5. “文件夹”填网盘里的路径，例如 `/阿里云盘/Obsidian`（如果用户的基本路径已是 `/阿里云盘`，就填 `/Obsidian`）。文件夹不存在时第一次同步会自动创建。
6. 点 **测试连接**。看到“已连接，可以写入”后保存。

## 5. 手机上使用

- 手机和 Alist 在同一个局域网时，直接用局域网地址即可。
- 在外面也要同步时，需要让手机能访问到 Alist，例如：路由器端口转发加 HTTPS、内网穿透工具，或 Tailscale 等组网工具。使用公网地址时务必开启 HTTPS。

## 常见问题

| 提示 | 原因与处理 |
|---|---|
| 不是 WebDAV 服务 | 地址后面少了 `/dav/`。 |
| 用户名或密码不对 | 检查用户名、密码；确认用户已勾选 WebDAV 权限。 |
| 没有权限 | 用户没有“WebDAV 管理（写入）”权限，或“文件夹”不在用户的基本路径之内。 |
| 网络连接失败 | 手机和 Alist 不在同一网络，或 Alist 没有运行。 |
| 同步很慢 | 网盘接口本身有速度和频率限制；第一次同步文件多时会比较慢，之后只传变化的文件。 |
