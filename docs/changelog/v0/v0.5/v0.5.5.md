# v0.5.5

- 日期：2026-11-01
- 对应提交：标签 `v0.5.5`（比较基准：`v0.5.4`）

## 修改

- 发布的 `main.js`、`manifest.json`、`styles.css` 附带 GitHub 来源证明（artifact attestation），用户可以验证这些文件是从本仓库源码构建的。
- 删除目的地、清空同步历史的确认按钮：Obsidian 1.13 起使用新的危险按钮样式，不再调用已弃用的 `setWarning`。
- 样式表去掉 `!important`、`:has` 和 `text-decoration`：手机上自动同步的输入框行改为按类名换行；上手清单里已完成的项不再加删除线，只变灰并打勾。

- 结果：单元测试 379 通过；ESLint 0 错误，剩 2 个警告（设置页尚未采用新的声明式设置写法）；构建通过
