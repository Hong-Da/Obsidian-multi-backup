# v0.5.8

- 日期：2026-11-20
- 对应提交：标签 `v0.5.8`（比较基准：`v0.5.7`）
- 摘要：主同步端更容易设置、更容易看到；清空历史按钮换新样式

## 新增

- 还没有主同步端时，保存新的在线目的地（Git、WebDAV、S3、网盘）后会问怎么使用，默认选主同步端；选了以后照常先只读比较，确认后才开始双向同步。也可以选“只做备份”。
- 这个窗口打开时只读查看目的地：已有其他设备的笔记时，写明有多少个文件可以下载、来自哪台设备。
- 导入的配置原来有主同步端时，导入完成的提示里直接有“设为主同步端…”按钮，不用再去设置里找。

## 改进

- 主同步端显示在更多地方：状态栏的提示和菜单（菜单里排第一并带标记）、设置页（排第一）、侧栏同步历史顶部（上次双向同步下载和上传了多少）。状态栏文字不变。
- 没有主同步端、但有在线目的地时，设置页和侧栏提示一句“现在只做备份”，可以直接设置，也可以关掉。
- 侧栏同步历史底部的“清空历史”改成带垃圾桶图标的小按钮，鼠标移上去变红。
- 发布说明补上发布后检查社区目录的步骤；开发时只用一个测试库。

## 测试情况

- 是否测试：是
- 测试范围：全部单元测试；电脑上的 Obsidian 检查侧栏的主同步端卡片和清空按钮；新版本已装进一个有 GitHub 主同步端的真实库，界面效果尚未确认
- 结果：单元测试 403 通过；ESLint 0 错误，剩 2 个警告（设置页尚未采用新的声明式设置写法）；构建通过
- 未覆盖：“怎么使用”窗口在 Obsidian 里的实际操作（测试库没有在线目的地）；手机
