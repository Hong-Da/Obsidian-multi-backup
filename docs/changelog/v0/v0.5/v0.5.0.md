# v0.5.0

- 日期：2026-10-31
- 对应提交：标签 `v0.5.0`（比较基准：`v0.4.1`）
- 摘要：M5 验收：插件配置备份、网盘目的地（Dropbox、OneDrive、Google Drive）

## 新增

- 网盘登录（M5-2）：OneDrive、Dropbox 用授权码 + PKCE，浏览器授权后跳回 `obsidian://multi-backup-auth`；Google Drive 用设备代码登录；令牌快到期时自动续期，只保存在本机密钥存储。
- 网盘目的地（REQ-009～REQ-011）：备份、历史版本、回收站、作主同步端都可用；只能访问插件自己的文件夹。
- Dropbox 已注册应用并填入 App key；OneDrive、Google Drive 的应用 ID 暂未填，界面提示“这个版本还不能登录”。

## 修复

- 令牌缓存第一次取到的令牌会一直用下去、不再续期。

## 涉及的功能

REQ-009、REQ-010、REQ-011（v0.4.1 已含 REQ-041～REQ-045）
