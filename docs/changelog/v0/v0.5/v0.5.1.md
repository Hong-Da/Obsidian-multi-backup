# v0.5.1

- 日期：2026-10-31
- 对应提交：标签 `v0.5.1`（比较基准：`v0.5.0`）
- 摘要：M6-1 性能（自动模式打的版本，见决策记录）

## 改进

- 远程 Git：文件树按提交号缓存，远程没变时不拉取、不读树；提交时只重写改动的目录；推送只发本次新写的对象；首次备份每 32 MB 分批推送。模拟器上改 1 个文件的增量从 16.6 秒降到约 3 秒。
- WebDAV、S3 同时上传 4 个文件；WebDAV 记住已确认的文件夹，遇到 423、429、503 等待后重试。高延迟网络下首次备份快约 3 倍。
- zip 快照：大文件分段压缩，压缩时编辑笔记不卡。

## 涉及的文件

`src/destinations/`（remote-git、git-push、webdav-fs、local-mirror、local-zip、types）、`src/core/`（executor、timers）、`src/sync-service.ts`、`tests/perf/`、`tests/unit/`（remote-git、git-push、executor、webdav-fs）、`tests/support/`、`scripts/test-services.sh`、vitest 配置。

## 测试情况

- 是否测试：是
- 测试范围：全部单元测试 + 测试机 Docker 集成测试 + 性能测试（5000 篇笔记 + 1 GB）+ Android 模拟器
- 结果：
  - 单元测试 353 通过；ESLint 0 错误
  - 集成测试 14 通过
  - 性能：Gitea 改 1 个文件 0.5 秒、WebDAV 0.3 秒（目标 10 秒）；同步时主线程最长占用 80 毫秒以内
  - 模拟器：GitHub、Gitee 改 1 个文件约 3 秒，主线程最长占用 6 毫秒
- 未覆盖：手机上 5000 篇笔记的全量验收（M6-2）；真实公网 GitHub 上的 1 GB 首次推送
