# v0.5.7

- 日期：2026-11-05
- 对应提交：标签 `v0.5.7`（比较基准：`v0.5.6`）
- 摘要：从备份恢复时可以选分支

## 新增

- 从 Git 目的地（本地 Git、远程 Git）恢复时，仓库有多个分支就可以在提交列表上方选分支，比如取回另一台设备备份到别的分支的笔记。
- 只读取选中的分支：不改目的地设置，不往那个分支推送；恢复出来的文件下次同步照常备份到原来的分支。
- 远程 Git 的其他分支在选中后才下载，和同步用的分支分开存放。
- 仓库只有一个分支时界面和以前一样。
