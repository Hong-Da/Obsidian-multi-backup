# v0.5.6

- 日期：2026-11-05
- 对应提交：标签 `v0.5.6`（比较基准：`v0.5.5`）
- 摘要：用 GitHub 登录；设置目的地时说明如何创建令牌、密码或访问密钥

## 新增

- GitHub 目的地可以“用 GitHub 登录”：在插件里拿到一个代码，到 github.com/login/device 输入并授权，再把插件的 GitHub 应用装到备份仓库即可，不用自己创建令牌。应用只能访问你选定的仓库，权限只有仓库内容的读写。登录信息只存在本机的密钥存储里。
- 登录后会检查备份仓库有没有装上应用，没装时给出“安装到仓库”按钮；同步时登录失效或应用没装，提示会说明该重新登录还是安装应用。
- 新建 GitHub 目的地默认用登录；已有的 GitHub 目的地和其他 Git 平台继续用手动填写的令牌。

## 改进

- 设置目的地时，每种目的地都有创建令牌、应用密码或访问密钥的步骤说明，并说明 GitHub 该创建哪种令牌、需要哪些权限。
- 每日同步时间的输入框改成和 Obsidian 其他输入框一样的样式。
- 在目的地弹窗里切换选项时，不再跳回顶部。

- 结果：单元测试 398 通过；ESLint 0 错误，剩 2 个警告（设置页尚未采用新的声明式设置写法）；构建通过；GitHub 登录实测通过
