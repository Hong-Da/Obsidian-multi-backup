# v0.5 汇总

包含版本：v0.5.0、v0.5.1、v0.5.2、v0.5.3、v0.5.4、v0.5.5、v0.5.6、v0.5.7

## 新增

- 网盘目的地：Dropbox、OneDrive、Google Drive（REQ-009～REQ-011，v0.5.0）
- 网盘登录：PKCE、obsidian:// 回调、Google 设备代码、自动续期（v0.5.0）
- 用 GitHub 登录，不用自己创建令牌（REQ-052，v0.5.6）
- 从备份恢复时可以选分支（REQ-054，v0.5.7）

## 改进

- 设置目的地时说明如何创建令牌、密码或访问密钥（REQ-051，v0.5.6）
- 性能：远程 Git 增量、WebDAV / S3 并发上传、zip 分段压缩（M6-1，v0.5.1）

## 修复

- S3 在 Android 上不能用；同步刚结束时的编辑不触发“修改后同步”（M6-2，v0.5.2）
