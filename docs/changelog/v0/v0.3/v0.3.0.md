# v0.3.0

- 日期：2026-10-31
- 对应提交：标签 `v0.3.0`（比较基准：`v0.2.0`）
- 摘要：M3 验收：主同步端双向同步、冲突处理、自动同步

## 新增

- 主同步端（REQ-013、REQ-015）：最多一个目的地在多台设备之间双向同步，目前支持远程 Git（GitHub / Gitee / 通用 Git）与本地镜像；一次同步先与主同步端双向同步，再推到各备份端。
- 设为主同步端前先只读比较，列出首次同步会下载、上传、保留两份的数量，确认后才开始；首次同步不删除任何文件。新设备由此从主同步端取回全部笔记（REQ-027）。
- 冲突处理（REQ-017～REQ-020）：两边都改了时保留两份，远程版本另存为 `<文件名>.conflict-<设备名>-<时间>.<扩展名>`；一边改一边删时保留修改的版本并提醒。冲突提醒、状态栏冲突数、冲突列表侧边栏、对比视图（手机上用标签切换），可保留本机 / 保留远程 / 两份都保留。
- 自动同步（REQ-022～REQ-024）：每个目的地可设定时、修改后、启动时、每天固定时间；错过的每日时间下次打开补做；关闭 Obsidian 前同步一次（桌面端）；自动同步成功不弹通知，失败只提醒一次。
- 设置页：主同步端标记与菜单、冲突数与“处理冲突”、本设备名称（只存本设备）、被同步覆盖或删除的本机文件保留天数、关闭前同步。

## 安全

- 覆盖或删除本机文件前，确认它在同步过程中没被再次编辑，并先复制到 `.trash/multi-backup/<日期>/`，默认保留 30 天。
- 推送失败时不把改动记为已同步；冲突副本不重复生成。
- 主同步端推送时远程刚被另一台设备更新：本次失败、下次重新比较，不覆盖对方的修改。
