# v0.3.1

- 日期：2026-10-31
- 对应提交：标签 `v0.3.1`（比较基准：`v0.3.0`）
- 摘要：M4-2 WebDAV、M4-3 S3 兼容存储

## 新增

- WebDAV（REQ-007，M4-2）：内置坚果云、Nextcloud、Alist、其他四种预设，每种附填写说明；阿里云盘、百度网盘等通过 Alist 接入，步骤见 [docs/alist.md](../../../alist.md)。服务器上的文件夹不存在时自动创建。
- S3 兼容存储（REQ-008，M4-3）：AWS S3、阿里云 OSS、腾讯云 COS、Cloudflare R2、MinIO 预设，选服务商时自动填好地址、地域和路径风格；SigV4 签名自己实现（WebCrypto），用 AWS 官方样例校验。
- 两种都复用本地镜像的逻辑：历史版本、回收站都在 `.multi-backup/` 下，可以做主同步端，手机上也能用并自动同步。
- 远程版本号优先用服务器的 ETag，避免 WebDAV 修改时间只到秒带来的误判。
- 凭据：WebDAV 密码、S3 Secret Access Key 只存本机密钥存储，设置里只记密钥名；S3 Access Key ID 存设置。
- 新的错误提示：不是 WebDAV 服务、找不到桶。

## 修复与调整

- 集成测试服务改用 rclone serve s3 / serve webdav（MinIO 镜像已无法公开拉取）。
