## 新增

- WebDAV（REQ-007，v0.3.1）：坚果云、Nextcloud、Alist、其他四种预设与填写说明；阿里云盘、百度网盘等通过 Alist 接入（[docs/alist.md](../../../alist.md)）。
- S3 兼容存储（REQ-008，v0.3.1）：AWS S3、阿里云 OSS、腾讯云 COS、Cloudflare R2、MinIO 预设；SigV4 签名自己实现（WebCrypto）。
- WebDAV、S3 都能做主同步端，手机上也能用并自动同步。
- 从备份恢复（REQ-025、REQ-026）：选择目的地和版本 → 选择整个 Vault 或文件夹、文件 → 预览写回、覆盖、跳过的数量后恢复。git 按提交、zip 按快照，镜像、WebDAV、S3 为当前备份；远程 Git 查看更早的提交时按需加深拉取。
- 单个文件的历史版本：文件右键“历史版本…”，列出各目的地中这个文件的版本，标出和现在不同的行，可以恢复其中一个。
- 入口：命令面板“从备份恢复…”“当前文件的历史版本…”、同步历史侧边栏顶部、状态栏菜单、文件右键菜单。

## 安全

- 恢复只改本机文件，不改动任何目的地；被覆盖、被移走的本机文件先另存到 `.trash/multi-backup/restore-<时间>/`，可在完成通知或同步历史中一键撤销；撤销时的本机文件也另存到 `undo-<时间>/`。
- 整个 Vault 恢复时默认不删除本机多出的文件；同步排除的路径恢复时也不碰；恢复进行中不同步。
- WebDAV 密码、S3 Secret Access Key 只存本机密钥存储。
