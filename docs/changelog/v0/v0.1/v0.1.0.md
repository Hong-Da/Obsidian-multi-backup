# v0.1.0

- 日期：2026-10-31
- 对应提交：标签 `v0.1.0`（比较基准：无，初始版本）
- 摘要：初始版本，M1 验收：桌面端本地镜像与 zip 快照，手动同步

## 新增

- 本地文件夹镜像（REQ-001）：目标文件夹中保存一份与 Vault 相同的副本；被覆盖的文件保留最近 10 个历史版本，Vault 中删除的文件移到回收站保留 30 天，都放在目标文件夹的 `.multi-backup/` 下。
- zip 快照（REQ-002）：每次同步把 Vault 打包成带时间的 zip；按“最近 N 个且不超过 D 天”清理旧快照；Vault 没有变化时不生成新快照。
- 多个目的地并存（REQ-012）：可添加、编辑、复制、删除、暂停；一个目的地失败不影响其他目的地。
- 单向备份与增量同步（REQ-014、REQ-016）：只处理变化的文件；识别重命名，改名的文件在目标中直接改名；单个文件失败下次自动重试。
- 手动同步（REQ-021）：侧边栏顶部、状态栏菜单、命令面板（全部立即同步 / 同步单个目的地）。
- 文件范围（REQ-031～REQ-033）：排除规则（写法同 .gitignore，不区分大小写）、可选包含 Obsidian 配置文件夹、单个文件大小上限 50 MB。
- 状态栏（REQ-034）：已同步 / 同步中（带进度）/ 失败 / 未同步。
- 同步历史（REQ-035）：右侧边栏常驻，按天分组，可展开查看文件与错误，可筛选；功能区按钮一键打开。
- 失败通知（REQ-036）：说明原因与解决办法，带“查看详情”“编辑目的地”按钮。
- 日志（REQ-037）：令牌和密码自动隐藏，保留 14 天，可导出到 Vault 根目录。
- 设置页与目的地弹窗（REQ-038）：测试连接（能否写入、剩余空间、已有文件或快照数）；目标文件夹在 Vault 里面或包含 Vault 时禁止保存。
- 中英文界面（REQ-040），跟随 Obsidian 的语言设置。
