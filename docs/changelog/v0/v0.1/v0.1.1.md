# v0.1.1

- 日期：2026-10-31
- 对应提交：标签 `v0.1.1`（比较基准：`v0.1.0`）
- 摘要：M2-2 凭据、M2-3 本地 git 仓库、M2-4 远程 Git（GitHub / Gitee / 其他）

## 新增

- 凭据（REQ-039，M2-2）：令牌只存 Obsidian 的本机密钥存储，设置里只记密钥名；读取到的令牌自动从日志中隐藏。
- 本地 git 仓库（REQ-003，M2-3，仅桌面）：每次同步有变化时提交一次；可以用空文件夹或已有仓库；同步中途退出时下次补提交；`.git` 是文件（worktree、子模块）时提示不支持。
- 远程 Git（REQ-004～REQ-006，M2-4）：推送到 GitHub、Gitee 或任何 HTTPS Git 托管；仓库里原有的文件保留；远程被别处推进时把本次改动放到最新提交上再推送，不强推；本机只存 git 对象，不复制 Vault 文件。
- 设置页“添加目的地”菜单开放“本地 git 仓库”和“GitHub / Gitee / Git”；目的地列表与同步历史显示提交号。
- 令牌设置项带生成步骤（GitHub Fine-grained token 只开 Contents 读写；Gitee 只勾 projects）。

## 修复与调整

- 同步流程改为先收尾（提交、推送）再保存清单：推送失败的改动不会被记为已同步，下次同步会补推。
- 打包进 `buffer` 包，`main.js` 不再需要 Node 模块，移动端可以加载插件。
