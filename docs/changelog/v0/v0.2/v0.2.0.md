## 修复与调整

- 移动端经 DataAdapter 写文件偶尔留下 0 字节文件：写后核对大小并重试；已留下的空对象文件自动修复。
- 服务器拒绝推送（如分支保护）时提示“推送被拒绝”，原因写入日志；“没有推送权限”的提示加上检查仓库地址。
- 令牌设置项显示所选的密钥名；手机上 Change 按钮不再撑满整行。
- 设置页“全部立即同步”、弹窗“测试连接”按钮显示文字（原来只有图标）。
- 手机上打开目的地弹窗不再自动弹出键盘；“额外排除规则”输入框整行显示。
